# Food Delivery Web App (QuickBite)

## Overview
This project is a **full-stack Food Delivery Web Application** inspired by platforms like Zomato and Swiggy.  
It allows users to browse food items, place orders, and track deliveries, while admins can manage food items and orders.

## Features

### User Features
- Browse food items and categories
- Add items to cart
- Place orders securely
- User authentication (Login / Signup)
- View order history

### Admin Features
- Add / update / delete food items
- Manage orders
- Control inventory and pricing

### Payment & Orders
- Order placement system
- Cart management
- Checkout flow

## Tech Stack

### Frontend
- React.js
- CSS / Tailwind
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- JWT Authentication
- REST APIs

## System Architecture

1. **Frontend (React)**
   - Handles UI and user interaction
2. **Backend (Node + Express)**
   - Handles APIs, authentication, and business logic
3. **Database (MongoDB)**
   - Stores users, orders, and food data

## Workflow

1. User signs up / logs in  
2. User browses food items  
3. Adds items to cart  
4. Places order  
5. Backend processes order and stores it in the database  
6. Admin manages orders from the dashboard
